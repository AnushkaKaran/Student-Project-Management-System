# Student Project Management System (SPMS)

A full-stack web-based application designed to simplify and organize academic project management activities. The system provides a centralized platform for managing project-related information and improving collaboration between students, faculty, and administrators.

The application focuses on maintaining structured project records, tracking project activities, and providing an efficient workflow for academic project management.

---

## 🚀 Features

### 👨‍💼 Admin Management
- Manage student and faculty information
- Configure academic years and project categories
- Monitor project activities

### 👨‍🎓 Student Management
- Manage student profiles
- Create and manage project groups
- View project details

### 👨‍🏫 Faculty Management
- Faculty dashboard
- Manage assigned projects
- Track project progress

### 📁 Project Management
- Project group creation
- Project proposal management
- Project details tracking

### 📝 Meeting Management
- Schedule project meetings
- Maintain meeting records and attendance

### 📊 Reports
- Generate project-related reports
- Organize project information efficiently
